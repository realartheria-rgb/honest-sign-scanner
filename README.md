# «Честный Знак» — Сканер технических марок
Одностраничное PWA-приложение для iPhone.
Сканирует любой код маркировки: QR, Data Matrix, Aztec, GS1-128 (EAN-128), EAN/UPC.

## Функции
- Полноэкранный сканер с маской (бегущие углы)
- Парсер любого формата кода (GTIN, серийный номер, дата, объём)
- История в localStorage (до 200 записей)
- Тёмная тема, Apple-стиль, safe-area для iPhone
- PWA: добавление на «Домой», иконка 180×180

## Сборка
Никакой сборки — один HTML-файл со встроенными CSS/JS.
Библиотека: html5-qrcode (CDN).

## Запуск
Откройте `index.html` в браузере сHTTPS (или localhost) —
камера потребует разрешение при первом сканировании.
